# Milestone B1.3.1 — Public API Review

This milestone inventories and classifies the workspace public API, introduces preferred suite-first HPKE setup functions, preserves identifier-based compatibility wrappers, and adds a reproducible API inventory check.

## Commands

```bash
cargo xtask api-review
cargo xtask api-review --check
```

See `docs/api/API_REVIEW.md` and `docs/api/API_INVENTORY.md`.
