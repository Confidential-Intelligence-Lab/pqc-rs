# Stage 6.3 Internal Fixture Seed-Expansion Fix

The Stage 6.2 normative key-generation path changed seed expansion from:

```text
G(d)
```

to:

```text
G(d || k)
```

However, the Stage 5B-15 internal fixture builder still derived its expected
`rho` and `sigma` values with the older structural helper. It then compared
those values against the public key generated by the corrected parameter-aware
key-generation path.

That caused the fixture builder's `decoded_rho == seed_material.rho`
assertion to fail for all three parameter sets.

This patch changes the fixture builder to use:

```rust
expand_keygen_seed_for_parameter_set(parameter_set, &keygen_seed)
```

The internal fixtures will therefore remain deterministic while tracking the
current normative seed-derivation behavior.
