# Stage 9D-1A: ML-DSA Coefficient Encodings

This stage adds canonical low-level polynomial encodings for `eta`, `t1`, `t0`, `z`, and `w1`.
Aggregate public-key, private-key, and signature encodings follow in Stage 9D-1B.

Primary references: FIPS 204 and the official pq-crystals Dilithium reference implementation.
