# RFC 9958 Mapping

RFC 9958 is an informational engineering guide. This project uses it to organize implementation topics and protocol guidance, while normative conformance is traced to the standards that define each algorithm or protocol.

The initial mapping covers:

- ML-KEM, ML-DSA, and SLH-DSA identification;
- KEM security and binding considerations;
- HPKE integration;
- signature security context;
- parameter-selection trade-offs;
- hybrid constructions;
- implementation and side-channel considerations.

Generate the current report with `cargo xtask compliance`.
