# PQC-rs v0.4.0

`v0.4.0` promotes the validated `v0.4.0-rc.1` publication line to the
non-prerelease `0.4.0` version.

The promotion contains the same cryptographic implementations as the release
candidate. Its changes are limited to versions, dependency requirements,
documentation, lockfiles, and release tooling.

## Published packages

- `pqc-rs-core` `0.4.0`
- `pqc-rs-ml-kem` `0.4.0`
- `pqc-rs-hpke` `0.4.0`

ML-DSA, SLH-DSA, the experimental hybrid placeholder, and the test harness
remain outside the public publication boundary.

ML-DSA was subsequently published as an independent crate release without
changing this workspace tag's historical boundary. See the
[ML-DSA 0.4.0 release record](ML_DSA_0.4.0.md).

## Installation

```toml
[dependencies]
pqc-rs-core = "0.4.0"
pqc-rs-ml-kem = "0.4.0"
pqc-rs-hpke = "0.4.0"
```

## Security status

PQC-rs remains pre-1.0 and has not been independently audited. Removing the
Cargo prerelease suffix is not an assertion of production readiness.
Applications should continue to apply the security qualifications documented
in the repository.
