# Support

PQC-rs is a pre-1.0 open-source project.

Use public GitHub issues for reproducible bugs, standards questions, interoperability failures, and documentation defects. Use discussions, when enabled, for design questions and integration guidance.

Before opening an issue, include:

- the exact revision or package version;
- Rust and Cargo versions;
- operating system and architecture;
- enabled feature flags;
- a minimal reproduction;
- expected and observed behavior.

Security vulnerabilities must be reported privately according to `SECURITY.md`.

The project does not currently provide guaranteed response times, long-term support releases, or commercial support through the public repository.
